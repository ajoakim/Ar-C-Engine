<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| rustup toolchain -> build | The compiler toolchain selected by rust-toolchain.toml compiles all code |
| crates.io -> workspace | No external crates are added in this plan (path deps only) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | rust-toolchain.toml | mitigate | Pin exact version `1.99.0` (not `stable`) so builds are reproducible and an unexpected toolchain cannot be silently selected |
| T-01-02 | Tampering | Cargo.lock | mitigate | Commit Cargo.lock so future dependency resolution is reviewable in diffs; CI uses `--locked` (plan 04) |
| T-01-03 | Elevation of Privilege | unsafe code in stubs | mitigate | `[workspace.lints.rust] unsafe_code = "forbid"` inherited by every crate via `[lints] workspace = true` |
| T-01-04 | Information Disclosure | repository contents | accept | No secrets, credentials or runtime code in this plan |
</threat_model>
