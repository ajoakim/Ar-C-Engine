```rust
pub struct StreamManager<K: StreamKey, S: StreamSource<K>> {
    config: StreamConfig,
    residency: ResidencyManager,
    loader: AsyncLoader,
    source: Arc<S>,
    keys: BTreeMap<AssetId, K>,                                   // side table AssetId -> K (BTreeMap only; never HashMap)
    pending: BTreeMap<(Reverse<Priority>, u64), StreamRequest<K>>,// priority desc, then FIFO seq
    pending_index: BTreeMap<AssetId, (Reverse<Priority>, u64)>,
    next_seq: u64,
    in_flight: BTreeMap<AssetId, InFlight>,                       // started, not yet GpuResident
    completed: VecDeque<LoadEvent>,                               // polled, not yet applied (completion cap)
    ready: BTreeMap<AssetId, Vec<u8>>,                            // applied, awaiting upload
    frame: u64,
}
struct InFlight { priority: Priority, seq: u64, class: AssetClass, cancel: CancelToken }
impl<K: StreamKey, S: StreamSource<K>> StreamManager<K, S> {
    pub fn new(config: StreamConfig, residency: ResidencyManager, source: Arc<S>) -> Result<Self, StreamError>; // config.validate()?
    pub fn request(&mut self, req: StreamRequest<K>) -> Result<(), StreamError>;
    pub fn cancel(&mut self, key: &K) -> Result<bool, StreamError>;
    pub fn update(&mut self, jobs: &JobSystem, frame: u64, uploader: &mut dyn Uploader<K>) -> Result<FrameReport, StreamError>;
    /// BLOCKING: waits for every started job and buffers its completion. Test/shutdown only; never call on the frame path.
    pub fn settle(&mut self);
    pub fn pending_len(&self) -> usize; pub fn in_flight_len(&self) -> usize;
    pub fn pending_keys(&self) -> Vec<K>;          // queue order
    pub fn is_pending(&self, key: &K) -> bool;
    pub fn state(&self, key: &K) -> Option<ResidencyState>;
    pub fn residency(&self) -> &ResidencyManager;
    pub fn config(&self) -> StreamConfig;
}
```
`request` (no blocking, validates before mutating): id = key.asset_id(); Duplicate if id in pending_index or in_flight, or residency state is one of Requested/Generating/CpuReady/Uploading/GpuResident/Evicting; QueueFull if `pending.len() >= max_pending` (REJECT, orchestrator decision; never drop another request); if `residency.state(id).is_none()` call `residency.track(id, req.budget_class)?`; insert into keys, pending, pending_index with `seq = next_seq; next_seq += 1`.
`update` steps, in this order:
1. `self.frame = frame; residency.begin_frame(frame)`.
2. Sweep cancellations: pending entries whose `cancel.is_cancelled()` are removed; in-flight entries whose token is cancelled go through `cancel_in_flight(id)`; count into `cancelled`.
3. Start up to `max_starts_per_frame`: pop the first pending entry; `residency.request(id)?`; `est = source.estimate_bytes(&key)`; closure `let src = Arc::clone(&self.source); let k = key.clone(); move |tok: &CancelToken| src.produce(&k, tok)`; `loader.start(jobs, &mut residency, id, priority, est, closure)`: Ok -> insert InFlight (keep the request's seq); Err(AssetError::OverBudget { pool: MemoryPool::Cpu, .. }) -> `residency.cancel(id)?` (Requested -> Unloaded), re-insert the SAME entry (same priority+seq) into pending, stop starting this frame (back-pressure; 06-05 inserts an eviction attempt here); other Err -> `residency.fail(id)` and count `failed`.
4. `let events = loader.poll(&mut residency); completed.extend(events);` (poll never blocks).
5. Apply at most `max_completions_per_frame` from the front of `completed`: Loaded{id,data} with id in in_flight -> `ready.insert(id, data)`; Failed{id} -> `retire(id)`, failed += 1; Cancelled{id} -> `retire(id)`, cancelled += 1; each popped event counts toward completions_applied. Events for ids no longer in flight are dropped (cancelled after poll).
6. Uploads: order `ready` ids by (Reverse(priority), seq) from in_flight; for each: `gpu = data.len() as u64`; `residency.try_begin_upload(id, gpu)`: Ok -> if `uploader.upload(&key, &data)` then `complete_upload(id)?`, remove from ready, `retire(id)`, uploads += 1, uploaded_bytes += gpu; else `abort_upload(id)?` and keep. Err(UploadCapExceeded{..}) -> break; Err(OverBudget{pool: Gpu, ..}) -> continue (06-05 adds eviction); other Err -> return Err.
7. Fill FrameReport (pending, in_flight, deferred_completions = completed.len(), awaiting_upload = ready.len()).
`retire(id)` is the ONLY place that removes from `in_flight` (06-05 adds unpinning there). `cancel_in_flight(id)`: state Requested|Generating -> `loader.cancel(&mut residency, id)?`; state CpuReady -> remove any `LoadEvent::Loaded{id}` from `completed` (retain), `ready.remove(&id)`, `begin_evict(id)?`, `finish_evict(id)?`; then `retire(id)`. `cancel(key)`: pending -> remove, Ok(true); in_flight -> cancel_in_flight, Ok(true); otherwise Ok(false). `settle`: `let ev = self.loader.wait_all(&mut self.residency); self.completed.extend(ev);`. `update` must never call `wait_all`, `JobHandle::wait`, `sleep` or `Instant`.
