<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer -> resolve | Called every frame for every visible key; must be bounded and non-blocking |
| eviction policy -> residency data | Wrong eviction would remove data being displayed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-14 | Denial of Service | resolve ancestor walk | mitigate | Walk length bounded by key depth (StreamKey::parent chain ends at None); no allocation besides the returned key clone; no waits |
| T-06-15 | Denial of Service | pin leaks block eviction forever | mitigate | Single removal point `retire()` unpins; tests cover uploaded/failed/panicked/cancelled paths returning pin_count to 0 |
| T-06-16 | Tampering | evicting displayed data | mitigate | make_room filters pinned, in-flight, awaiting-upload and recently shown ids from the FULL candidate list (u64::MAX) |
| T-06-17 | Denial of Service | budget exhausted by pins | accept | Documented back-pressure: new requests wait in the bounded queue (tested); Phase 8 overlay surfaces it |
</threat_model>
