#[derive(Debug, Clone, PartialEq, thiserror::Error)]
pub enum MathError {
    #[error("non-finite coordinate or transform")] NonFinite,
    #[error("unknown frame {0:?}")] UnknownFrame(FrameId),
    #[error("frame transform is not invertible for {0:?}")] NonInvertible(FrameId),
    #[error("the root frame has no parent transform and cannot be rebased")] RootFrame,
    #[error("unknown position {0:?}")] UnknownPosition(PosId),
}
// world_pos.rs
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct WorldPos { frame: FrameId, local: DVec3 }          // fields private
impl WorldPos {
    pub fn new(frame: FrameId, local: DVec3) -> Result<Self, MathError>;   // NonFinite if any component NaN/inf
    pub fn from_xyz(frame: FrameId, x: f64, y: f64, z: f64) -> Result<Self, MathError>;
    pub fn frame(&self) -> FrameId;
    pub fn local(&self) -> DVec3;                              // read-only frame-local coords (meters)
    pub fn translated(&self, offset: DVec3) -> Result<Self, MathError>; // same frame
}

pub struct FrameId(u32);

Implementation notes:
- `FrameRegistry` stores `Vec<FrameData>`; FrameId is the index (u32). Root at index 0 with `parent: None` and `to_parent: DAffine3::IDENTITY`. Parents must already exist, so cycles are impossible by construction.
- `add_frame` validates: parent exists; all matrix3 and translation components finite (`is_finite()`), else NonFinite; `to_parent.matrix3.determinant().abs() > f64::EPSILON`, else NonInvertible(new id that would be assigned).
- `to_root(f)`: compose `parent_chain` transforms: result = T_parent_n * ... * T_f (apply child first).
- `convert(pos, to)`: if `pos.frame() == to` return pos. Otherwise find lowest common ancestor L by walking parents (collect ancestors of `to` into a Vec, walk up from `pos.frame()` until found). up = composed transform from pos.frame() to L; down = composed transform from `to` to L; result local = down.inverse().transform_point3(up.transform_point3(pos.local())). Use LCA (not always root) so nearby frames never round-trip through large root coordinates. Validate result finite.
- `delta(from, to)` = `self.convert(to, from.frame())?.local() - from.local()`.

Implement `PositionStore` and `rebase` per the interfaces block (per locked decision "Origin rebasing is an explicit `rebase(new_origin)` that shifts registered positions; trigger policy is left to app/module" — do NOT add any automatic trigger, threshold or engine-loop hook; that is a deferred idea).
`rebase(frames, store, frame, new_origin)` algorithm (validate everything first so an Err leaves state untouched):
1. If `frame == frames.root()` return Err(RootFrame). If `!new_origin.is_finite()` return Err(NonFinite). Check frame exists (UnknownFrame).
2. `frames.set_to_parent(frame, old_to_parent * DAffine3::from_translation(new_origin))` — the frame's origin moves to old-local point `new_origin`.
3. For every frame `c` whose parent is `frame`: `set_to_parent(c, DAffine3::from_translation(-new_origin) * old_c_to_parent)` so children keep their absolute placement. (Add a `pub fn children(&self, f: FrameId) -> Result<Vec<FrameId>, MathError>` helper to FrameRegistry in frame.rs only if needed; frame.rs edits are allowed since this plan owns it. If you edit frame.rs, list it in the SUMMARY.)
4. For every stored position whose `frame() == frame`: replace with `WorldPos::new(frame, local - new_origin)?`.
Document on `rebase` that f64 rebasing is not bit-exact in general (ulp at 6.4e6 m is ~9.3e-10 m) and repeated rebases accumulate bounded drift (research Pitfall 4). Tests live in `#[cfg(test)] mod tests` in rebase.rs (paths contain `rebase`). Use a helper `fn assert_vec_near(a: DVec3, b: DVec3, tol: f64)`.
