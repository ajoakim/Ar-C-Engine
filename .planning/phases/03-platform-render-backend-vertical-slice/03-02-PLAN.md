#[non_exhaustive] #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)] pub enum VertexLayout { PosColor } // stride() -> u64 == 24
#[derive(Debug, Clone, PartialEq, Eq)] pub struct PipelineDesc { pub label: &'static str, pub shader: ShaderId, pub vertex_layout: VertexLayout }

    fn create_pipeline(&mut self, desc: &PipelineDesc) -> Result<PipelineId, RenderError>;
    fn resize(&mut self, width: u32, height: u32);

    pub fn alloc_buffer(&mut self, desc: &BufferDesc, data: &[u8]) -> Result<BufferId, RenderError>;

    pub fn alloc_pipeline(&mut self, desc: &PipelineDesc) -> Result<PipelineId, RenderError>;

    pub fn pipeline(&self, id: PipelineId) -> Result<&PipelineDesc, RenderError>;

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Denial of Service | ResourceTable::validate_packet (stale/forged ids, OOB vertex counts) | mitigate | Ids never reused; every draw checks pipeline/buffer existence, usage and `vertex_count * stride <= size`, returning RenderError instead of panicking |

| T-03-07 | Tampering | Non-finite matrices / forward-Z clear reaching a GPU backend | mitigate | `mvp.is_finite()` and `clear_depth == 0.0` enforced in shared validation used by both backends |
| T-03-08 | Elevation of Privilege | unsafe byte casting of vertices | mitigate | `encode_vertices` uses `to_le_bytes`; workspace `unsafe_code = forbid` |
