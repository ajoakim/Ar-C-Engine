```rust
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct WorldTransform { pub position: WorldPos, pub rotation: glam::Quat, pub scale: glam::Vec3 }
impl WorldTransform {
    pub fn from_root(frame: FrameId, local: &Transform) -> Result<Self, WorldError>;   // WorldPos::new(frame, local.translation)?
    pub fn compose(&self, child: &Transform) -> Result<Self, WorldError>;
}
```
compose (translation math entirely in f64; never via Mat4/f32): `offset = self.rotation.as_dquat() * (self.scale.as_dvec3() * child.translation)`; `position = self.position.translated(offset)?`; `rotation = (self.rotation * child.rotation).normalize()`; `scale = self.scale * child.scale`. Document TRS-only (non-uniform scale with rotated children cannot express shear).
error.rs append `#[error("world transform of {0:?} is dirty; call update_transforms")] DirtyTransform(EntityId)`.
world.rs: extend private Node with `dirty: bool, cached: Option<WorldTransform>`; spawn/spawn_child set dirty = true. Private `fn mark_subtree_dirty(&mut self, id)` with explicit stack. Call it in set_local (after validation), set_parent, detach. Add:
```rust
pub fn update_transforms(&mut self) -> usize; // returns number of nodes recomputed
pub fn world_transform(&self, id: EntityId) -> Result<WorldTransform, WorldError>; // StaleEntity | DirtyTransform | Ok(cached)
pub fn world_position_in(&self, id: EntityId, frames: &FrameRegistry, target: FrameId) -> Result<WorldPos, WorldError>; // world_transform(id)?.position then frames.convert
```
update_transforms: for each root in `self.roots()` (sorted, deterministic) do an explicit-stack DFS carrying `(id, parent_world: Option<WorldTransform>, force: bool)`; recompute node if `node.dirty || force`, using from_root(node.frame, &local) for roots and parent_world.compose(&local) for children; on composition Err (overflow to non-finite) leave node dirty with cached None and skip its subtree (document; no panic). Children are pushed with `force = recomputed`. Clear dirty on success, increment counter. Because mark_subtree_dirty already dirties descendants, `force` is a belt-and-braces guarantee.
