```rust
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct HashGridConfig { pub cell_size: f64, pub max_cells_per_entity: u64 }
impl Default for HashGridConfig { cell_size: 64.0, max_cells_per_entity: 512 }  // Claude's discretion (ADR-0006)
type CellKey = [i64; 3];
struct Entry { bounds: Aabb, cells: Option<(CellKey, CellKey)> /* None = oversize */ }
pub struct HashGridIndex { frame: FrameId, config: HashGridConfig, cells: HashMap<CellKey, Vec<EntityId>>, entries: BTreeMap<EntityId, Entry>, oversize: BTreeSet<EntityId> }
impl HashGridIndex {
    pub fn new(index_frame: FrameId, config: HashGridConfig) -> Result<Self, SpatialError>; // cell_size finite and > 0, max_cells_per_entity >= 1
    pub fn config(&self) -> HashGridConfig;
    pub fn cell_count(&self) -> usize;      // non-empty cells
    pub fn oversize_count(&self) -> usize;
}
impl SpatialIndex for HashGridIndex { ... }
```
Cell key: `fn cell_coord(v: f64, cell: f64) -> i64 { (v / cell).floor() as i64 }` (Rust float->int `as` saturates, so no UB/panic; inputs are finite by Aabb validation). Cell range of an Aabb = (key(min), key(max)). Span count = product over axes of `(hi - lo) as i128 + 1` computed in u128 with checked_mul (overflow -> treat as oversize). If span > max_cells_per_entity -> oversize set, `cells = None`; else push id into each cell Vec. remove/update: remove id from each cell Vec (`retain`), drop cells whose Vec becomes empty, remove from oversize, then re-insert for update.
Queries (shared private fn `query_with(range_box: &Aabb, pred: impl Fn(&Aabb) -> bool, out)`): `out.clear()`; compute the query's cell span (region: the region; radius: sphere.bounds(); frustum: frustum.bounds()). If span (u128, checked) > entries.len() as u128 (or overflowed) -> fallback: iterate `entries` (BTreeMap, sorted) and push ids whose bounds satisfy pred. Else iterate all cells in the range, extend candidates from each existing cell, extend with oversize ids, `sort_unstable(); dedup()`, then keep ids whose `entries[id].bounds` (use `get`, never index) satisfy pred. Output order ascending by EntityId; HashMap iteration order must never leak into output.
lib.rs: `mod hash_grid;` + `pub use hash_grid::{HashGridConfig, HashGridIndex};`. Update the crate doc to name HashGridIndex as the default backend.
Unit tests in hash_grid.rs `mod tests` named per <behavior>.
