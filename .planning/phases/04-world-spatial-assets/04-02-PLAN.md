```rust
pub fn set_parent(&mut self, child: EntityId, parent: EntityId) -> Result<(), WorldError>;

```
set_parent order of checks (all before any mutation): child live else StaleEntity(child); parent live else StaleEntity(parent); child == parent -> SelfParent(child); walk ancestors of `parent` iteratively (loop over `.parent`), if `child` is found -> Cycle{child, parent}. Then remove child from old parent's `children` (retain), push into new parent's children, set node.parent. Local transform is kept as-is and is reinterpreted relative to the new parent (document "keeps local, not world"). If child already has that parent, return Ok(()) without reordering.
detach: StaleEntity check; remove from old parent's children; parent = None; frame = `frame`; local kept. Detach of an existing root just updates its frame.
