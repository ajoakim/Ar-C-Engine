```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum LoadEvent { Loaded { id: AssetId, data: Vec<u8> }, Failed { id: AssetId }, Cancelled { id: AssetId } }
type Completion = (AssetId, u64, Option<Vec<u8>>);   // None = producer returned None (treated as failure)
pub struct AsyncLoader { tx: mpsc::Sender<Completion>, rx: mpsc::Receiver<Completion>, pending: BTreeMap<AssetId, (u64, JobHandle)>, abandoned: Vec<JobHandle> }
impl AsyncLoader {
    pub fn new() -> Self;   // impl Default
    pub fn start<F>(&mut self, jobs: &JobSystem, manager: &mut ResidencyManager, id: AssetId, priority: Priority, cpu_bytes: u64, produce: F) -> Result<(), AssetError>
        where F: FnOnce(&CancelToken) -> Option<Vec<u8>> + Send + 'static;
    pub fn cancel(&mut self, manager: &mut ResidencyManager, id: AssetId) -> Result<(), AssetError>;
    pub fn poll(&mut self, manager: &mut ResidencyManager) -> Vec<LoadEvent>;
    pub fn wait_all(&mut self, manager: &mut ResidencyManager) -> Vec<LoadEvent>;
    pub fn pending_len(&self) -> usize;
}
```
start: `manager.begin_generating(id, cpu_bytes)?` first (state/budget errors return before any submit); `gen = manager.request_generation(id).ok_or(AssetError::UnknownAsset(id))?`; clone tx; `jobs.submit(priority, move |tok| { if tok.is_cancelled() { return; } let r = produce(tok); if tok.is_cancelled() { return; } let _ = tx.send((id, gen, r)); })`; insert into pending (if an entry for id already exists, its handle is cancelled and moved to `abandoned`).
cancel: remove pending entry, `handle.cancel()`, push handle into `abandoned`, then `manager.cancel(id)` (bumps request generation so any late message is stale).
poll (order matters, documented): (1) snapshot `try_status()` for every pending entry; (2) drain `rx.try_recv()` until empty: for each `(id, gen, r)` apply only if `pending.get(&id)` has the same gen; `Some(data)` -> `manager.finish_generating(id, gen)` Ok -> remove pending, push Loaded{id, data}; `None` -> `manager.fail(id)`, remove pending, push Failed; mismatched/unknown messages are dropped silently; (3) for ids still pending whose snapshot was `Some(Panicked)` -> `manager.fail(id)`, push Failed; `Some(Cancelled)` -> `manager.cancel(id)` if state is still Generating, push Cancelled; `Some(Completed)` with no message is impossible by the ordering argument but handle defensively as Failed. Also drop `abandoned` handles whose try_status is Some(_). Events returned sorted by AssetId for determinism. Manager errors during apply (e.g., asset untracked meanwhile) drop the completion, never panic.
wait_all: take every pending handle, `wait()` each (blocking; deterministic for tests), also wait all `abandoned`; then run the same apply logic using the collected statuses as the snapshot. No `sleep` anywhere.
lib.rs: `mod loader;` + `pub use loader::{AsyncLoader, LoadEvent};`. Re-export nothing from engine-jobs (callers depend on engine-jobs directly).
Unit tests in loader.rs `mod tests` named per <behavior> (use `JobSystem::builder().workers(1).start_paused(true).build()`).
