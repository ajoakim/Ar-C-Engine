```rust
pub enum ResidencyState { Unloaded, Requested, Generating, CpuReady, Uploading, GpuResident, Evicting, Failed }
impl ResidencyState {
    pub const ALL: [ResidencyState; 8] = [Unloaded, Requested, Generating, CpuReady, Uploading, GpuResident, Evicting, Failed];
    pub const fn index(self) -> usize;   // position in ALL
    pub fn can_transition(self, to: Self) -> bool;
    pub fn transition(&mut self, to: Self) -> Result<(), AssetError>;
    pub fn is_in_flight(self) -> bool;
}
```
can_transition: an exhaustive `match self { ... }` with one arm per source state using `matches!(to, ...)` for the allowed targets; NO wildcard `_ => true` arm and no catch-all over source states. Legal edges (17, pinned; research A3 accepted):
- Unloaded -> Requested
- Requested -> Generating | Failed | Unloaded (cancel)
- Generating -> CpuReady | Failed | Unloaded (cancel)
- CpuReady -> Uploading | Evicting | Failed
- Uploading -> GpuResident | Failed | CpuReady (upload aborted)
- GpuResident -> Evicting
- Evicting -> Unloaded
- Failed -> Requested (retry) | Unloaded
Document the table in the module doc.

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub struct ClassBudget { pub cpu_bytes: u64, pub gpu_bytes: u64 }
struct ClassState { budget: ClassBudget, cpu_used: u64, gpu_used: u64 }
struct Record { class: AssetClass, state: ResidencyState, cpu_bytes: u64, gpu_bytes: u64, last_used_frame: u64, request_gen: u64 }
pub struct ResidencyManager { classes: BTreeMap<AssetClass, ClassState>, records: BTreeMap<AssetId, Record>, upload_cap_bytes: u64, uploaded_this_frame: u64, frame: u64, next_request_gen: u64, denied_uploads_cap: u64, denied_uploads_budget: u64 }
impl ResidencyManager {
    pub fn new(upload_cap_bytes: u64) -> Self;
    pub fn set_class_budget(&mut self, class: AssetClass, budget: ClassBudget);   // create or replace; lowering below usage is allowed, only new reservations fail
    pub fn track(&mut self, id: AssetId, class: AssetClass) -> Result<(), AssetError>;   // state Unloaded
    pub fn untrack(&mut self, id: AssetId) -> Result<(), AssetError>;                    // only from Unloaded or Failed (no bytes held), else IllegalTransition{from, to: Unloaded}
    pub fn state(&self, id: AssetId) -> Option<ResidencyState>;
    pub fn request_generation(&self, id: AssetId) -> Option<u64>;
    pub fn frame(&self) -> u64;
    pub fn begin_frame(&mut self, frame_index: u64);                 // sets frame, uploaded_this_frame = 0
    pub fn request(&mut self, id: AssetId) -> Result<u64, AssetError>;          // Unloaded|Failed -> Requested; assigns and returns new request_gen (monotonic)
    pub fn begin_generating(&mut self, id: AssetId, cpu_bytes: u64) -> Result<(), AssetError>; // Requested -> Generating; reserves cpu bytes
    pub fn finish_generating(&mut self, id: AssetId, request_gen: u64) -> Result<(), AssetError>; // Generating -> CpuReady; StaleRequest if gen differs; touch
    pub fn cancel(&mut self, id: AssetId) -> Result<(), AssetError>;            // Requested|Generating -> Unloaded; release; bump request_gen
    pub fn fail(&mut self, id: AssetId) -> Result<(), AssetError>;              // -> Failed where legal; release cpu+gpu; bump request_gen
    pub fn try_begin_upload(&mut self, id: AssetId, gpu_bytes: u64) -> Result<(), AssetError>; // CpuReady -> Uploading
    pub fn complete_upload(&mut self, id: AssetId) -> Result<(), AssetError>;   // Uploading -> GpuResident; touch
    pub fn abort_upload(&mut self, id: AssetId) -> Result<(), AssetError>;      // Uploading -> CpuReady; release gpu bytes (uploaded_this_frame not refunded, documented)
    pub fn touch(&mut self, id: AssetId) -> Result<(), AssetError>;             // last_used_frame = frame
    pub fn begin_evict(&mut self, id: AssetId) -> Result<(), AssetError>;       // CpuReady|GpuResident -> Evicting
    pub fn finish_evict(&mut self, id: AssetId) -> Result<(), AssetError>;      // Evicting -> Unloaded; release cpu+gpu
}
```
Rules: every operation validates the full precondition set (record exists, transition legal via `ResidencyState::can_transition`, budget/cap checks using `checked_add`, `AccountingOverflow` on overflow) BEFORE mutating anything; a single private `fn release(&mut self, id)` subtracts the record's cpu_bytes/gpu_bytes from its class with `saturating_sub` and zeroes them. Byte holding: cpu bytes held in Generating, CpuReady, Uploading, GpuResident, Evicting; gpu bytes held in Uploading, GpuResident, Evicting.
try_begin_upload check order: legal transition; cap rule `if uploaded_this_frame > 0 && uploaded_this_frame + bytes > cap` -> denied_uploads_cap += 1, Err(UploadCapExceeded{needed: bytes, remaining: cap.saturating_sub(uploaded_this_frame)}) (oversize-asset rule A4: an asset larger than the cap may upload only as the first upload of a frame, so it cannot starve); gpu budget `gpu_used + bytes > gpu_budget` -> denied_uploads_budget += 1, Err(OverBudget{pool: Gpu, needed, available}). On success: gpu_used += bytes, uploaded_this_frame += bytes, record.gpu_bytes = bytes. Denial counters are the only fields a failed call may change (documented observability).
lib.rs: `pub use manager::{AssetClass, ClassBudget, MemoryPool, ResidencyManager};`.
Tests in manager.rs `mod tests` named per <behavior> (prefix `budget_`). Use `AssetId::from_key("a")` etc. for ids.
