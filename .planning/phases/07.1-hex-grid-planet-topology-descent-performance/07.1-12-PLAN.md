`hex/mapping.rs` (whole file is border-critical: no `usize`, no banned tokens; module doc states the invariant):
- `pub const VERTICES: [[f64; 3]; 12]` built from `phi = (1 + sqrt(5)) / 2` (a `fn vertices() -> [[f64; 3]; 12]` computing with sqrt is fine; cache in a `const` only if exact literals are used) in the orientation validated by S2.
- `#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord)] pub struct LatticePoint { pub face: u8, pub a: u64, pub b: u64, pub c: u64, pub d: u64 }` with `a + b + c == d`; `pub fn canonical(self) -> LatticePoint` (shift a, b, c, d right while all even; for points on a face edge or vertex choose the lowest face index among the faces containing it, mapping weights through the shared vertices).
- `pub fn sample_dir(p: LatticePoint) -> DVec3`: canonicalise, sum the non-zero weights times their vertex in ascending GLOBAL vertex index order, component-wise x, y, z, then divide by `sqrt(x*x + y*y + z*z)`.
- Cell frame: `pub fn cell_center_point(c: CellId, n: u32) -> LatticePoint` on the sample lattice `d = 3 * n * 2^L` (cell centre = level-L lattice vertex), `pub fn cell_corner_points(c: CellId, n: u32, out: &mut Vec<LatticePoint>)` (6 or 5 corners = centroids of the incident level-L lattice triangles, in direction order), and `pub fn cell_sample_point(c: CellId, n: u32, sector: u8, s: u32, t: u32) -> LatticePoint` = `centre + s*(corner_k - centre)/n + t*(corner_{k+1} - centre)/n` evaluated in integers in an unfolded face frame and mapped back to the owning face (sector k spans the two lattice triangles on either side of lattice direction k; points with s > t, s < t, s == t fall in the respective face or on the shared edge). Require `n` even and `1 <= n <= 64`.
- `pub fn footprint(c: CellId) -> Footprint`: centre dir; `cos_delta` = min dot of the centre with all corner dirs and the 6 (5) edge-midpoint dirs (sample lattice points), minus `1e-12`; `sin_delta = sqrt(max(0, 1 - cos^2))`.
- `pub fn locate(dir: DVec3, level: u8) -> CellId`: face by max dot with the 20 face normals (ties -> lower face), barycentrics by solving with the precomputed inverse (+ - * /), cube-coordinate rounding with `floor`, then the cell region test against the up-to-7 candidate cells (choose the candidate whose centre has the largest dot product; this is the hex region in the face lattice to within the projection, document the approximation and its test tolerance).
- `hex/mod.rs`: `pub mod mapping;` and re-exports.
