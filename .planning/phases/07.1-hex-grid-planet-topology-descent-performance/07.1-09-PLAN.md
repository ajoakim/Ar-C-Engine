<objective>
The one generic core change of this phase (CONTEXT "Architecture"): shared static index buffers with index-range draws in engine-render, engine-render-wgpu and engine-sdk, plus ADR-0013 (ADR-0011 is reserved for the hex topology; 0012 is the LOD-selection ADR from 07.1-05).

Purpose: half-cell drawing needs one vertex buffer per cell and several shared index lists (full hex, pentagon, 6 halves); without range draws each edge child would need two meshes (~1.9x draws). It also halves buffer counts for the quadtree.
Output: API, validation, wgpu draw path, tests, ADR-0013.

<decision_dependency>
GO and FALLBACK: execute as written (the triangle fallback also benefits from shared index lists). STOP: do not execute.
</decision_dependency>

</objective>
