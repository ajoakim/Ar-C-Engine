# Phase 07.1 Plan 10: Hex CellId and tables Summary

Production `hex` module in planetary-core: packed `u64` CellId (base 63..60, level 59..55, Morton 54..7, low 7 bits zero) with full validation, const icosahedron/diamond tables, and integer-only neighbour/child/parent derivation with separate per-edge enumeration for the 12 pentagons. Decision was GO (07.1-07).

## What was built

- `hex/icosa.rs`: const `FACES` (20), `DIAMONDS` (10, origin at obtuse corner), `corners`; no floats.
- `hex/cell_id.rs`: `CellId`, `CellIdError {StrayBits, BadBase, BadLevel, CoordOutOfRange, PoleCoord}`, `HEX_MAX_LEVEL = 24`, `new/from_raw/raw/base/level/ij/is_pole/north_pole/south_pole/level_iter`.
- `hex/adjacency.rs`: `canonical`, `is_pentagon`, `DIRS`, `neighbors`, `children`, `parents`, `primary_parent`. Internals: integer face barycentrics, edge reflection, and an `owner` inverse (support-vertex test per diamond triangle) replacing the spike's BTreeMap/OnceLock tables. Only `std` plus the crate; no HashMap/usize in coordinate math (usize only for array indexing).

## Test evidence

- `hex_cell_id`: 5 passed (round_trip_all_cells_to_level_6, level_counts, rejects_invalid_raw, ordering, icosa tables).
- `hex_adjacency`: 8 passed (exactly_twelve_pentagons_per_level L0..6, neighbors_reciprocal, children_counts, parents_round_trip, pentagons_never_edge_children, children_cover_next_level incl. two-parent cells = 3V-6 edges, deep_levels_sampled at L12/L24 with 1000 boundary-biased cells each, canonical).
- Full `cargo test -p planetary-core --locked` green (hex_spike 17, banned_ops 2, all pre-existing tests unchanged). `cargo test -p planetary-terrain --locked --no-run` OK.

## Deviations from Plan

- [Design] The plan's "static wrap table" is implemented as a computed reflection (same as the validated spike logic, minus its cache). Out-of-contract input to `canonical` is clamped (T-07.1-27) with a debug assertion rather than panicking.
- Neighbour/edge-child ordering is direction order, not raw-sorted (plan says "direction order" for children).
