<domain>
## Phase Boundary

Make the planet descent work at the real default parameters (detail streams in, frames hold budget, no crash, measurable) on an H3-inspired hex-grid planet. Closes Phase 7 gaps G1-G3 (`07-VERIFICATION.md`). Requirements: HEX-01, HEX-02, HEX-03, PERF-01, PERF-02. All planetary code stays under `extensions/planetary/*`; the core and SDK stay planet-agnostic (the planetary-absent CI canary must keep working).

User intent (their words): the hex grid was inspired by Uber's H3; "as you descend details would render, each hex giving way to its constituent parts, sort of deaggregation of the mesh, and aggregation on ascent." The Phase 7 flight showed detail not rendering in on descent; the scripted descent stuttered and crashed (cause unknown); they want frame rate measurable against distance/descent height.

<decisions>
## Implementation Decisions (locked by user, 2026-11-25)

### Topology
- Use the **half-cell 4-children hex grid on an icosahedron** ("B*" in HEX-TOPOLOGY.md): hexes around face vertices, `10*4^L+2` cells per level incl. 12 pentagons; a hex gives way to one centre hex plus 6 edge hexes, each edge hex half-covered by this parent (the neighbour completes the other half). Real H3 is rejected as render geometry (7 children don't nest: ~7.3% parent area gaps; needs trig). No H3 ID compatibility; an H3 adapter may come later.
- Edge children have two parents; streaming uses the lower ID as the fallback parent. A cell may split only when all its parents are split; neighbours of those parents split too (keeps adjacent drawn pieces within one level).
- Gnomonic projection using only `+ - * / sqrt` (ADR-0008 exact arithmetic; area ratio ~1.96). Equal-area projections (need trig) are out unless an ADR supersedes ADR-0008.
- u64 cell ID: 10 face-pair "diamonds" + 2 poles, level, Morton(i,j); 24-level capacity.
- Fallback if sphere spikes fail: draw nested triangles over the same lattice and use hexes only for IDs/overlay.

### Crack-free technique
- Keep ADR-0010: skirts + shared-border sampling from one continuous planet-space height function; the seam proof (with negative control) carries over, plus a new coverage proof (every point drawn exactly once). Borders-without-skirts (parent border interior to children, Nanite-like) is deferred.

### Architecture
- Add a small **`Topology` trait** now; keep the cube-sphere quadtree as a second implementation and as test oracle/fallback until hex passes the full descent at real parameters. Minimal surface only.
- One generic core change: shared index buffers with **index-range draws** in the SDK/render path (fallback: two meshes per edge child, up to ~1.9x draws). Needs an ADR (ADR-0011 is reserved for the hex topology decision; use the next free number for this one).
- Borrow Nanite ideas only: tight bounds from generated geometry, error rule that never decreases toward coarser levels, always-resident coarse levels (already via pinned fallback), hierarchical culling. No cluster DAG, visibility buffer or GPU-driven pipeline in this phase.

### Sequencing (user chose "fix + measure first, spike hex, then go/no-go")
1. Telemetry + crash diagnosis (parallelizable, topology-independent).
2. Selection fixes on the EXISTING quadtree (closes G1; gives a working descent early): distance to the cell footprint extruded between its own min/max height (relief only extends vertically), height ranges from the nearest resident ancestor + a bound for finer octaves, horizon culling (Cesium-style, exact-op) + frustum culling, node-visit budget, remove tau-escalation reruns, respect the 1024-draw limit (overflowing draws are currently dropped silently -> holes; make that explicit/impossible).
3. Spikes S1-S4 on the sphere (ID layout gives exactly 12 pentagons per level; adjacency/ID round trips; half-cell coverage on the sphere; skirt gap bound on half-cell diagonals) -> **explicit go/no-go decision with the user** before the full hex build.
4. Hex build: IDs/adjacency tables, projection, Topology trait, selection/balance/drawn pieces, meshes + seam/coverage proofs, generic index-range draw, make TerrainSystem topology-generic, planetary app + descent test at REAL defaults.

### Defaults
- Default max level 16 (the current generator's finest noise wavelength is ~32 m; deeper adds nothing), 16 cells per sector side, ID capacity 24 levels. Real ~1 m detail (level 18 + ~19 noise octaves) is a later step, not this phase.
- Estimated draws ~120-350 (within the 1024 cap) - confirm with telemetry; the descent test must run at the real default max level (no reduced level like Phase 7's test at 13).

### Telemetry / diagnosis (PERF-01, PERF-02)
- Frame time (avg/p95/max), FPS, altitude above surface, distance to surface, nodes visited, wanted/drawn leaves, held meshes, pending, started/uploaded/evicted per frame; console summary ~1 Hz; `--perf-log <file.csv>`; headless `--bench-descent` at real defaults with per-altitude-band stats and pass/fail against a stated budget; works in debug and `--release`.
- Wall-clock only inside a clearly named telemetry module (or an injected clock) so deterministic tests and the no-wall-clock scans stay valid. The on-screen overlay is Phase 8 (QA-02), but the data model must be reusable by it.
- Crash diagnosis must be evidence-based: capture the panic/error text (RUST_BACKTRACE), per-frame timing at real params, unbounded growth of held meshes/pending requests/buffers/memory, wgpu limits and device-lost paths, resource exhaustion. Leading suspects (unconfirmed): near-full disk (C: ~6 GB free, can break pagefile/allocations), unbounded leaf counts, debug-build selection cost multiplied by tau-escalation reruns (8x).

### Claude's Discretion
Plan breakdown (~10-12 plans per research), crate/module layout under extensions/planetary, spike harness form, constants, ADR numbering beyond 0011.

## Existing Code Insights

### Survives unchanged
planetary-terrain TerrainSystem streaming glue (to be made topology-generic), planetary camera, planetary-app, SDK `App::gpu_frame` + `Resources::destroy_mesh`, engine-streaming, engine-procedural, exact-op golden policy.

### Replaced / generalized
planetary-core cube-sphere topology/ID/adjacency/mapping/LOD/balance/mesh/seam proofs become one implementation of the `Topology` trait; hex gets its own.

### Known root cause of G1 (topology-independent)
Node bounds are spheres inflated by global max relief (~3.8-6 km), so every node within that horizontal distance gets distance ~1 m and splits to max level; tau escalation reruns selection up to 8 times; no culling; draws beyond MAX_DRAWS_PER_FRAME are dropped silently.

### Constraints
Rust 1.99.0, `unsafe_code = forbid`, clippy -D warnings, cargo-deny, the exact-op rule (no sin/cos/exp/ln/powf/tan/mul_add/usize/HashMap in hashed or border-critical paths; concat!-built tokens in scans), check-deps + check-canary + xtask layer table/docs policy must stay green, disk very tight (no extra target dirs, no heavy deps), CI on 3 OSes (hosted CI blocked by GitHub billing; cross-target `cargo check` for linux-gnu and aarch64-apple-darwin locally), human window flights required for final verification.
