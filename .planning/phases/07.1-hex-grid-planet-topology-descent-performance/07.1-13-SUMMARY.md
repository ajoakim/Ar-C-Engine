# Phase 07.1 Plan 13: Generic TerrainSystem Summary

`TerrainSystem<T: Topology>` now streams, uploads and draws any topology. Workers produce v3 cell payloads (`Topology::build_mesh` + `encode_cell_payload`); the frame thread validates with `decode_cell_payload` and uploads vertex-only buffers (`create_lit_vertices`). `setup` builds one shared static index buffer per vertex class (all variants concatenated, per-variant `(class, first, count)`), and `gpu_frame` draws each piece with `MeshHandle::with_index_range`. `TerrainConfig.debug_cells` selects a 16-row debug palette. Streaming caps and request ordering are untouched; per-frame logic stays in `prepare` (request planning) and `gpu_frame` (upload/cut/draw) so 07.1-19 can extend it.
