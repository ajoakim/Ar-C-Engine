<interfaces>
lod/select.rs: `screen_space_error(model, view, id, range, min_distance) = model.geometric_error(level) * view.proj_scale / max(cell_distance(radius, eye, footprint, range), min_distance)`; `LodParams.tau_px` default 2.0, `hysteresis` 0.2. topology/select.rs evaluates `rho = model.geometric_error(topo.level(id)) * view.proj_scale / d` with `d = cell_distance(model.radius, view.eye, &fp, range)` clamped to `params.min_distance`; a cell splits when `rho > tau` (or `> tau * (1 - hysteresis)` if previously split). Therefore a cell of level `k` is refined once its distance falls below `d_k = geometric_error(k) * proj_scale / tau`. The existing test `hysteresis_band_has_zero_toggles` computes exactly this `d_star`.
`LodModel::geometric_error(level) = max(kappa * cell_size, sagitta)` (halves per level when the kappa term dominates, quarters per level when the sagitta term dominates at coarse levels, so the ratio d_(k-1)/d_k is between 2 and 4).
system.rs gpu_frame (read 2026-11-26): loops `eff.pieces`; for each drawn piece it has `h.range` (measured height range), the view in `self.last_view`, `self.topo.footprint(leaf)`, and pushes `RenderItem` built with `RenderItem::new(..).with_material(..)` (plan 21). `self.drawn_set` is cleared every frame. `cell_distance` and `HeightRange` are in `planetary_core::lod`.
RenderItem::with_morph(f32) exists since plan 21 (clamped to [0,1] at extract).
</interfaces>
