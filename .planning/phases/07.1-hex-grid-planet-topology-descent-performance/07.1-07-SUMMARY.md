### Caveats carried into the build

1. The S4 skirt model is loose (27x to 1000x margin) and was validated only to coarse level 4 on the real hierarchy (deeper levels use an interior construction). It does not validate the 1.5 margin against the real LodModel error measure; the later mesh and seam plans must test against it.
2. Pentagons need separate per-edge neighbour enumeration; the diamond-plane wrap is only valid for non-vertex cells.
3. `locate` uses the gnomonic-lattice Voronoi (differs from spherical Voronoi on 1.18 percent of samples), so selection and bounds code must use the lattice definition consistently.
4. The neighbour half of the balance closure measured as not needed for max jump 1, but it is kept in the full rule so half pieces never face finer cells (cost 4.58 vs 0.97 forced splits per pick). The finding is empirical, not a proof.
5. The icosahedron stays unrotated (exact-op); the poles are not on a coordinate axis.
6. The S2 negative control is weak; skip-zero-weight is insurance, not a discriminating test.
