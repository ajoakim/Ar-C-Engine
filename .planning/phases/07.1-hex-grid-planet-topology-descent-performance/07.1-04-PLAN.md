`lattice.rs` (test-only; integer math only; use BTreeMap/BTreeSet, never HashMap):
- Icosahedron as 12 vertices (index 0 = north pole, 1-5 upper ring, 6-10 lower ring, 11 = south pole) and 20 faces listed with vertices in a fixed orientation; 30 edges.

Each diamond d has origin vertex O_d (one of the 10 ring vertices, each used exactly once), and axes towards two vertices I_d and J_d; lattice point `(i, j)`, `0 <= i, j < 2^L`, owned by diamond d (half-open, so the far edges belong to neighbouring diamonds or the poles). - `fn canonical(d, level, i: i64, j: i64) -> Cell`: maps any lattice coordinate (possibly negative or >= 2^L) to its owning diamond/pole through a static wrap table (derive the table from the shared icosahedron edges; build it with a `const fn` or a lazily computed `BTreeMap` in the test).
