Create `tests/descent.rs`. Shared helper `fn run(cfg_mut: impl Fn(&mut AppSettings), frames: u32) -> Vec<FrameRecord>` where settings = `AppSettings { terrain: TerrainConfig { cells_per_edge: 16, lod: LodParams { max_level: 16, ..Default::default() }, settle_each_frame: true, workers: 2, ..Default::default() }, script: Some(DescentScript::orbit_to_surface(radius)), ..Default::default() }` then `cfg_mut`; drive `Runtime::new(Engine::new(EngineConfig::default()), NullBackend::new())`, `rt.setup`, loop `rt.frame(&mut app, 1.0 / 60.0)?` (simulated clock: constant dt, never Instant/sleep); record per frame `FrameRecord { report: TerrainReport, drawn: Vec<u64> (raw ids), wanted_len, draws (from NullBackend last_frame), buffer_count, held, altitude }`. Constants: `FRAMES = 600` (8 s descent + 2 s hover), `WARM_UP = 10`, `NODE_VISIT_CAP = 50_000`, `CONVERGE_WITHIN = 120`.
Tests:
1. `descent_within_counted_caps`: every frame: stream.started <= cfg.stream.max_starts_per_frame; completions_applied <= max_completions_per_frame; uploads <= uploads_per_frame; uploaded_bytes <= uploads_per_frame * payload_len(16); requests_issued <= max_requests_per_frame; stream.pending <= stream.max_pending; select.nodes_visited <= NODE_VISIT_CAP; select.leaves <= lod.max_leaves or tau_steps == max_tau_steps; draws <= MAX_DRAWS_PER_FRAME; draw_overflow == 0; request_errors == 0; upload_rejects == 0. eprintln the per-run maxima (started, uploads, uploaded_bytes, nodes_visited, drawn, held, tau_eff) for the ADR.
2. `descent_crack_free_every_frame`: for frame >= WARM_UP: drawn non-empty, `is_partition(drawn)`, `drawn_max_jump <= 1`.
3. `descent_reaches_surface_and_converges`: altitude at frame 480 (t = 8 s) <= 3.5 m above `surface_radius_at`; within CONVERGE_WITHIN frames after 480 there is a frame where drawn == wanted leaves exactly.
4. `descent_is_deterministic`: two runs -> identical Vec of (started, completions_applied, uploads, drawn).
5. `descent_degrades_with_one_start_per_frame`: `stream.max_starts_per_frame = 1`, `max_completions_per_frame = 1`: started <= 1 every frame, partition + balanced every frame after WARM_UP, drawn never empty after WARM_UP.
6. `descent_no_gpu_leak`: every frame buffer_count == 2 * held and held <= base patches (6*(4^4-1)/3 + 16) + detail_budget_patches; also with `detail_budget_patches = 60`: sum evicted > 0 and the invariant still holds.
7. `production_path_never_blocks`: `settle_each_frame = false` (real async path, non-deterministic timing): 600 frames complete, caps of test 1 hold every frame, partition + balance hold every frame where drawn is non-empty, and drawn_leaves > 0 by the last frame. No timing assertions.
Keep runtime < 240 s in debug (N = 16, max_level 16); if slower, reduce FRAMES to 480 + 60 hover and record the change in the SUMMARY.
