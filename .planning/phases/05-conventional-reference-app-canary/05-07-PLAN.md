`check_uri`: `data:` prefix -> Ok. Otherwise if `base.is_none()` -> `ExternalReference(uri)`. Otherwise reject (`UnsupportedUri(uri.to_owned())`) if empty, starts with '/', contains any of `':'`, `'\\'`, `'%'`, `'?'`, `'#'`, or any '/'-separated segment is empty, "." or "..". (The `%` rule prevents the gltf 1.4.1 urlencoding `unwrap` panic; the `:` rule rejects `file:` schemes and Windows drive paths.)
`decode_image`: `bytes.len() as u64 > limits.max_file_bytes` -> FileTooLarge; reader = `ImageReader::new(Cursor::new(bytes)).with_guessed_format()?`; format must be `Some(ImageFormat::Png | ImageFormat::Jpeg)` else `UnsupportedImageFormat`; `(w, h) = reader.into_dimensions()?` on a fresh reader, `w == 0 || h == 0 || w > max || h > max` -> `TextureTooLarge { width: w, height: h, max }` (zero -> Image("zero-sized image")); then a fresh reader with `image::Limits` (max_image_width/height = max_texture_dimension, max_alloc = max_image_alloc), `decode()?`; color type must be one of `L8, La8, Rgb8, Rgba8` (else `UnsupportedImageFormat`, rejecting 16-bit/float); `to_rgba8()` -> ImportedTexture. No V flip (glTF uv origin matches wgpu).

pub fn import_gltf_path(path: &Path) -> Result<ImportedModel, ImportError>;                          // default limits
pub fn import_gltf_path_with(path: &Path, limits: &ImportLimits) -> Result<ImportedModel, ImportError>;

`import_gltf_path_with`: `fs::metadata(path)?.len() > max_file_bytes` -> FileTooLarge (before reading); `fs::read`; base = `path.parent()`; delegate.
`import_gltf_slice_with` steps:
1. `bytes.len() as u64 > max_file_bytes` -> FileTooLarge. `let gltf::Gltf { document, blob } = gltf::Gltf::from_slice(bytes)?;` (validates indices/references).
2. URI pre-flight: for every buffer with `Source::Uri(uri)` and every image with `image::Source::Uri { uri, .. }`: `check_uri(uri, base)?`; for non-`data:` URIs also `fs::metadata(base.join(uri))?.len() <= max_file_bytes` else FileTooLarge.
3. `let buffers = gltf::import_buffers(&document, base, blob)?;`
4. Textures: collect the set of image indices referenced by any material's `base_color_texture()` with `tex_coord() == 0` (others ignored, documented). For each referenced image (ascending index) get bytes: `View { view, .. }` -> `buffers.get(view.buffer().index())` and `view.offset()..view.offset().checked_add(view.length())` bounds-checked with `.get(range)` (else `InvalidAccessor("image buffer view out of range")`); `Uri { uri, .. }` -> `gltf::buffer::Data::from_source(gltf::buffer::Source::Uri(uri), base)?`; `decode_image(&bytes, limits)?`; record image index -> ImportedTexture index in a `HashMap<usize, usize>`.
5. Materials (document order): base_color_factor must be finite (else `NonFinite("material base color")`); texture = mapped index if referenced with tex_coord 0.
6. Meshes: for each gltf mesh (document order) and each primitive: skip (with `engine_sdk::tracing::debug!`) if `primitive.mode() != Mode::Triangles` or `read_positions()` is None. positions: count > `max_vertices_per_mesh` -> TooManyVertices (check `reader.read_positions()` len via `ExactSizeIterator::len()` before collecting); all finite else `NonFinite("position")`. uvs: `read_tex_coords(0).map(|t| t.into_f32().collect())`, length must equal positions else `InvalidAccessor("TEXCOORD_0 count mismatch")`, default `[0.0, 0.0]`; finite. indices: `read_indices().map(|i| i.into_u32().collect())` else `(0..n as u32).collect()`; len > max_indices -> TooManyIndices; `len % 3 != 0` -> `InvalidAccessor("index count not a multiple of 3")`; any `i >= n` -> `InvalidIndex { mesh, index: i, vertex_count: n }`. normals: `read_normals()` with matching length and all finite, else `generate_normals(&positions, &indices)` (area-weighted face-normal accumulation, normalized, `(0,1,0)` for zero-length). Push `ImportedMesh` with `material: primitive.material().index()`; keep `mesh_map: Vec<Vec<usize>>` (gltf mesh index -> ImportedMesh indices).
7. Nodes: scene = `document.default_scene().or_else(|| document.scenes().next())`; none -> empty nodes. ITERATIVE DFS (explicit `Vec` stack, no recursion) over `(node, parent: Option<usize>, depth)`, pushing children in reverse so pre-order is document order; `visited: HashSet<usize>` on `node.index()` -> repeat = `HierarchyCycle`; `depth > max_depth` -> `HierarchyTooDeep { max }`; `nodes.len() >= max_nodes` -> `TooManyNodes { max }`. Local transform from `node.transform().decomposed()`: `Transform::new(DVec3::new(t[0] as f64, t[1] as f64, t[2] as f64), Quat::from_array(r), Vec3::from_array(s))`; reject `!is_finite()` or `rotation.length() < 1e-6` -> `NonFinite("node transform")`; normalize rotation. `meshes = node.mesh().map(|m| mesh_map[m.index()].clone()).unwrap_or_default()` (use `.get()`; out of range -> InvalidAccessor). Invariant (documented on ImportedNode): `parent < own index` (pre-order) — the scene builder in 05-09 relies on it.
No `unwrap()`/`expect()`/indexing that can panic on document data (use `.get()`); `unsafe` is forbidden by workspace lints anyway.
